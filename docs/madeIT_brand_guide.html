Usage Rules
Do
Use Signal Blue on dark for primary CTAs
Keep "IT" visually distinct — weight or color
Maintain whitespace around the logo
Use Space Mono for data, labels and tagline
Don't
Stretch or distort the logo
Use low-contrast blue on light gray
Stack more than 2 font weights on one element
Use the monochrome logo on colored backgrounds
